# Herding Cats

A family organiser for children's activities, study plans, homework and money.
It runs in the browser, installs to the home screen on phone and PC, and works offline.
No family data is ever stored in this repository.

- **Phase 1** (branch `Root`, bookmark `phase-1-final`): local-only beta, all data on the device. Live on GitHub Pages; frozen.
- **Phase 2** (branch `phase-2`): family accounts and shared sync on Google Firebase (database in Johannesburg).
  Every change is tested on Firebase's emulators by GitHub Actions, then published to Firebase Hosting.
